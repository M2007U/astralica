this is a mechanism to change the meaning of a word
it works with nouns, verbs, and adjectives.

/Fahaxen/ also has the meaning "to change, or to process something"

>[!note] Glyph Derivation
>derived from the shape of a blender
>and it is mentioned here : https://www.youtube.com/watch?v=3geaNq-82DU

>[!note] Pronunciation Derivation
>from the English word "Function"
>from the Chinese word "Hua"

the way we use it is to use the following structure :

![[fahaxen.png\|32]]![[KaxiRae.png\|32]]![[empty_128.png\|64]]![[AstralicaSlots_Number-1.png\|64]]![[empty_128.png\|64]] ![[fahaxen.png\|32]]![[KaxiKo.png\|32]]![[empty_128.png\|64]]![[AstralicaSlots_Number-2.png\|64]]![[AstralicaSlots_Number-3.png\|64]]![[empty_128.png\|64]]![[fahaxen.png\|32]]![[KaxiRa.png\|32]]

/Faræ (Slot1) Faro (Slot2)(Slot3) Fara/

where Slot1 is the word we want to manipulate or alter or modify
and Slot2 is the operation we want to use which is the part we define how to modify the word
and Slot3 is the value to describe how is the manipulation is done

sometimes in casual speak,
we can omit /Faræ/ and /Fara/
and we can treat /Faro/ as : will manipulate the word before it based on the given information behind it

# Operation 1 - Crank up or Crank down

derived from [[🟡 01 - Adjectives]], here we can use /Skla/ or /Sklæ/

![[fahaxen.png\|32]]![[KaxiRae.png\|32]]![[empty_128.png\|64]]![[AstralicaSlots_Number-1.png\|64]]![[empty_128.png\|64]] ![[fahaxen.png\|32]]![[KaxiKo.png\|32]]![[empty_128.png\|64]]![[AstralicaSlots_Number-2.png\|64]]![[AstralicaSlots_Number-3.png\|64]]![[empty_128.png\|64]]![[fahaxen.png\|32]]![[KaxiRa.png\|32]]

Slot1 is the main word we want to manipulate
Slot2 is either /skla/ or /sklæ/
Slot3 is a [[🟡 04 - Prime Factor Script]] number to describe "how far we crank it"

>[!example] the rain is getting WORSE QAQ
> refer to [[🔵 aramæin]]

there are 2 ways to crop this long sentence:
- for this special case, we will crunch
	/Fahaxen/ + /Skla/ into /Flask/ and
	/Fahaxen/ + /Sklæ/ into /Flæsk/
	and then put if after the word we want to manipulate, then followed by a [[🟡 04 - Prime Factor Script]]
- we can use /Flask/ or /Flæsk/ as a post fix for the word, and every post-fix-attaching will crank up/down the value

![[fahaxen.png\|32]]![[Event_Adjective_Crank_High.png\|32]] or ![[fahaxen.png\|32]]![[Event_Adjective_Crank_Low.png\|32]]

>[!example]
>here's 4 ways to say the word "big storm"
>1. proper method : /Faræ aramæin Faro Skla Na Fara/
>2. Faro focused : /aramæin Faro Skla Na/
>3. Fahaxen + Skla/æ : /aramæin Flask Na/
>4. post-fix : /aramæin-flask-flask-flask/

# Operation 2 - Extract Param

derived from [[🟡 01 _ Jikalæ - Ji _ Extract]] 

sometimes we can extract the value of a parameter of a noun or object.
but based on how the speaker uses this and how the listener interpret subjective discriptions, this does not guarantee that this is will work perfectly.

![[fahaxen.png\|32]]![[KaxiRae.png\|32]]![[empty_128.png\|64]]![[AstralicaSlots_Number-1.png\|64]]![[empty_128.png\|64]] ![[fahaxen.png\|32]]![[KaxiKo.png\|32]]![[empty_128.png\|64]]![[Kalaeji - Jikalae.png|64]]![[AstralicaSlots_Number-3.png\|64]]![[empty_128.png\|64]]![[fahaxen.png\|32]]![[KaxiRa.png\|32]]

Slot1 : the word we are manipulating
Slot2 : /Jikalæ/, set operation to "extract"
Slot3 : the parameter that we want to extract

>[!example]
>/ "apple" Faro Jikalæ LiTaraka /
>"apple" is the word or object we want to manipulate or extract parameters from
>/LiTaraka/ means "Color", which is the parameter
>in this case, this whole line means "red"

>[!warning] err no ~ Apple is green ~
>this is why we say /Faro Jikalæ/ will not work perfectly, more conversation needs to take place in order to have enough context and information

sometime to make things easier,
we can turn /Faro Jikalæ/ into /Faji/

![[fahaxen.png\|32]]![[Kalaeji - Jikalae.png|64]]

# Operation 3 - Broaden meaning

derived from [[🟡 01 _ Zoiga - Zoi _ Group]]

sometimes we can broaden the meaning of a certain word.
usually we use this on nouns (but it is possible to use it on adjectives and verbs)

another way to interpret this is that this operation destroys information, it can be though as the opposite of [[🟡 01 _ Kosra - Koa _ NULL]] information segments. It makes it slightly unspecific what we are talking about

![[fahaxen.png\|32]]![[KaxiRae.png\|32]]![[empty_128.png\|64]]![[AstralicaSlots_Number-1.png\|64]]![[empty_128.png\|64]] ![[fahaxen.png\|32]]![[KaxiKo.png\|32]]![[empty_128.png\|64]]![[zoiga.png\|64]]![[empty_128.png\|64]]![[fahaxen.png\|32]]![[KaxiRa.png\|32]]

/Faræ (Slot1) Faro Zoi Fara/

>[!example]
>apple -> red colored fruits *(can be cherries ? or tomatoes ?)*
>ant -> small insects *(small bugs ?)*
>knife -> sharp items *(swords ? saw ? basically anything that is sharp)*
>cat -> Felis Group *(Tigers ? Lions ? Cheetas ?)*

sometimes to make it shorter
we can turn /Faro Zoi/ into /Fazoi/
