## Using 2 parameters : Energy & Valance

Here, a range of emotions can be described by using 2 parameters
- Energy : how strong or weak an emotion is
- Valance : is it positive ? or it is negative ?

this means we can borrow some words we have :
- /Woki/ from [[🟡 03 - Physical Units]]
- /Yola/ from [[🟡 02 _ Yonila - Yola _ Goodness]]

in this case, the whole structure of an Emotion word is
```
Qimara - <EnergySegment> - <ValanceSegment>
```

and both the Energy Segment and Valance Segment can be broken down into
```
<EnergySegment>  = (Wa/Wæ)(0/1/2/3/4)
<ValanceSegment> = (Ya/Bu)(0/1/2/3/4)
```

where
- if the Energy is :
	- low, we use /Wæ/
	- high, we use /Wa/
- if the Valance is :
	- negative, we use /Bu/
	- positive, we use /Ya/
- and 0,1,2,3,4 is just /No,Ni,Næ,Na,Lo/, just like counting
