# Efficiency Compression

most of the cyborgs comes with audio processors (or they can install it) to help send and process sound signals in a much faster speed

the format being used is **"Astralica Audio Text Compression Format"**
the sound signal has mainly 3 parameters :
- wave type
	- sine wave
	- triangle wave
	- sawtooth
	- square wave
- rhythm :
	- if a dot is a tick, then a dash is 3 ticks,
	- between 2 dots or dashes, one tick of pause is required
	- between a letter, 3 ticks,
	- between a word, 7 ticks
- pitch
	- 1f is "do"
	- 3f is "so"
