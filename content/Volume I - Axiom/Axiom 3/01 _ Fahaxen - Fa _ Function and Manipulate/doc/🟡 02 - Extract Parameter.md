sometimes we can extract the value of a parameter of a noun or object.
but based on how the speaker uses this and how the listener interpret subjective discriptions, this does not guarantee that this is will work perfectly.

Slot1 : the word we are manipulating
Slot2 : /Jikalæ/, set operation to "extract"
Slot3 : the parameter that we want to extract

>[!example]
>/ "apple" Faro Jikalæ LiTaraka /
>"apple" is the word or object we want to manipulate or extract parameters from
>/LiTaraka/ means "Color", which is the parameter
>in this case, this whole line means "red"

>[!warning] err no ~ Apple is green ~
>this is why we say /Faro Jikalæ/ will not work perfectly, more conversation needs to take place in order to have enough context and information

sometime to make things easier,
we can turn /Faro Jikalæ/ into /Faji/
