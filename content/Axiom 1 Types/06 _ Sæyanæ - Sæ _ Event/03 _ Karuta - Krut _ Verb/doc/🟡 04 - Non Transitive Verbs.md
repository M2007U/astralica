
Most of the non-Transitive verbs can be described by using the following structure, these are called "structured non-transitive verbs"
so far all the non-transitive verbs can be considered as "Body Part Verbs", it is like "verbs acting on yourself"

The prefix looks a little scarry but here we can try to compress it with a shorter pronunciation

/Karuta + KosraNi + Zoiga + KaxiTæ/
→ /Krut + Koi + Zoi + Katæ/
→ /Kruoiztæ/

## Facing Vector

here, by convention, we will treat the direction of the head as "front"
here "Facing Vector" refers to the facing direction of the body.

here are a few examples :
Facing Front : standing, strolling, walking, runing
Facing downwards : crawling
Facing upwards : Lying, Backcrawling
Facing Sideways : foward straffing

here we will use **Simple Vector Notation** in [[🟡 03 _ KaxiAra - Ara _ Direction]]

---



## Height Specification

Sometimes, different verbs have the same velocity and facing direction, take the following as example :

"crouch, kneel, sit, half stand, stand, stretch"

all of these are facing front and standing still
the only parameter that changes is the height.
In this slot we can fill in one of the following :

here we will use [[🟡 04 - Prime Factor Script]]

## Movement Behavior

Not all verbs are continuos, some of them are in pulses, or in oscilation.
here are a few examples :
- Walking has a continous constant velocity
- Rocking is repeating a certain path
- Jump is a sudden pulse going up but dragged back onto the ground due to gravity.

Here, we can fill in this slot by using either one of them:
