
In this script, the numbers are arranged around the origin point of a 2D cartesian plane with the same direction when an angle is increasing. This is usually used for periodic systems like Cylic Fields and Angles or Maps.

>[!hint]
>In trigonometry, the ending side of an angle starts from the positive side of the X-axis, then rotates anti-clockwise as the angle increases, here the quadrant script reflects this property

>[!Hint]
>the "L"-shape in each glyph represents the X-axis and the Y-axis,
> with this we can also identify which quadrant they are in
