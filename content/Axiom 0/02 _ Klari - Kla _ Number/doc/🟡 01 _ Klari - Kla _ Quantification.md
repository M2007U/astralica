
## Astralica is Base 16

Astralica numbers uses positional-base-notation
meaning : based on the glyph's position, it represents the amount of the power of the base

>[!example] Base Ten Example
>$128 = 8 \times 10^0 + 2 \times 10^1 + 1 \times 10^2$

since Astralica is based on Computer Science, Astralica uses a base 16 positional system, aka : Hexadecimal

If you need more help with different bases, here's a video we have :

![](https://www.youtube.com/watch?v=Xquq9cA7Ias)

Astralica has multiple scripts and methods to write the same set of 16 digits,
Each script is designed and created for different purposes.

## Pronunciation

**Primitive Digits**
Each digit has its own pronunciation, but unlike other usual language, Astralica follows a straight pattern to say the numbers from 0x0 to 0xF :

|     |     |        |        |        |        |
| --- | --- | ------ | ------ | ------ | ------ |
| x   | <   | +0     | +1     | +2     | +3     |
| ^   | ^   | /o/    | /i/    | /æ/    | /a/    |
| 0   | /n/ | 0 /no/ | 1 /ni/ | 2 /næ/ | 3 /na/ |
| 4   | /l/ | 4 /lo/ | 5 /li/ | 6 /læ/ | 7 /la/ |
| 8   | /d/ | 8 /do/ | 9 /di/ | A /dæ/ | B /da/ |
| C   | /t/ | C /to/ | D /ti/ | E /tæ/ | F /ta/ |
Normally we would just literally say the digits from left to right like how we would read out a bar code or a phone number.

>[!example]
>"0xCA256" will be pronounced as /to - dæ - næ - li - ni/

**Power Specification**

Like in English we have "ones", "tens", "hundreds", "thousands".

|      |        |
| ---- | ------ |
| /so/ | $16^0$ |
| /si/ | $16^1$ |
| /sæ/ | $16^2$ |
| /sa/ | $16^3$ |

>[!example]
>using the previous example 
>"0xCA256" can be technically pronunciated as /to dæ sa næ sæ li si ni so/

>[!warning] but why do we need this thou ?
>consider the number "0xF000",
>without the mechanism, we would end up with /ta no no no/
>with this mechanism, we can have /ta sa/

just like in English we have "thousand", "million", "billion", and so on.

|      |           |
| ---- | --------- |
| /ro/ | $16^0$    |
| /ri/ | $16^4$    |
| /ræ/ | $16^8$    |
| /ra/ | $16^{12}$ |
>[!example]
>"0x F 0000 0000 0000" is /ta ra/

>[!note]
>most of the time, /so/ and /ro/ can be omited



To put everything together, we have the following structure :


|      |      |      |      |      |      |      |      |      |      |      |      |      |      |      |      |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| /sa/ | /sæ/ | /si/ | /so/ | /sa/ | /sæ/ | /si/ | /so/ | /sa/ | /sæ/ | /si/ | /so/ | /sa/ | /sæ/ | /si/ | /so/ |
|      |      |      | /ra/ |      |      |      | /ræ/ |      |      |      | /ri/ |      |      |      | /ro/ |


**Decimal Points**

we can also have decimal points in a number, just like our normal human decimal points.
the decimal point is pronounced as /pi/, written as a dot just like normal human convention.

>[!hint]
>/kia-kiæf-pi/ is a verb "to cut something with a knife", here /pi/ is a general verb "to split, to cut"

## /Klari/ > /Kla/

/Klari/ is used to represent "Quantification".
The symbol is derived from the different "ones" from
Quadrant Script, Binary Script, and Prime Factor Script.

Sometimes we need this symbol or this concept to "quantify" some traits or concept

![[Klari.png\|50]]

>[!note] Pronunciation derivation
>The pronunciation is inspired by
> "**q**uantity" from English, "**li**ang" from Chinese, and "**ry**o" from Japanese,
> we can get "Kaliri", and it is compressed to "Klari"

>[!example]
>"Quantification of Space" can be "Length", "Area", "Volume", etc
>"Quantification of Time" can be "Duration"
>"Quantification of Object" can be just "Quantity"
>"Quantification of Light Amplitude" can be "Brigthness"
>these concepts will be covered in future chapters
