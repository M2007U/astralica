**Original Sentence**
*"We will eat with your sister"*

before immediately diving into the translation
we need to make some adjustments:
*"We and my sister will eat"*

now we can disect the first layer 
```
We and my sister
eat ( will )
```

and here we can use Zoiga
```
AndStart
	We
AndMiddle
	me
	Possissive-Dettach
	sister
AndEnd
eat
InfoStart
	time : future
InfoEnd
```

and now we can translate it into Astralica
```

	Koix-ato //including us and you, depends on scenario
Zoio-Ro
	Koix-ino

Zoio-Ra

```

here thankfully the sentence is simple enough :
if commonsense and context is enough and provided
we can assume "we and my sister" will "eat"
- for the Zoiga Expression, there are only 2 operands
- for the information attachment for eat, there is only timePosition

but from this simplification
we can also squint hard enough and see another meaning :
in this case, it is not a complete sentence, instead it is a Zoiga Expression :
the pronoun "We" and the NounClause "My sister will eat"
