>in this phase, we can consider that
>when we start with /ə/ and put our tongue forward, we will get /i/ : this is considered a morph
>and with this update, when we start with /ə/, and clench our teeth narrower, we will get /ɪ/, and pull our jaw back, we will get /ø/

>at this phase, Glottal stop is treated as a vowel because it cuts a diphthong into 2 parts
>don't worry, as Astralica evolves, the glottal stop will be considered as a consonant
