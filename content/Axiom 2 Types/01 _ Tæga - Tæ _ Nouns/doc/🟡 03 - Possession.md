/Tæya/ is used for things that are dettached from the host
/Tæyu/ is used for things that are attached to the host

the noun / nounClause before /Tæyu/ or /Tæya/ is the host, what comes after is the possession.

>[!note] Glyph derivation
>mainly derived from the "right side arrow" ">" and the [[🟡 02 - Modification Characters]] /æra/ and /æru/

>[!example]
>"NyanChan's right ear", here we will use "Tæyu"
>"KytzunæChan's pencil", here we will use "Tæya"

>[!example]
>here are a list of things that are USUALLY for /Tæyu/ or /Tæya/
>
>for /Tæyu/
>- body parts
>- name
>- passion
>- knowledge
>- creation
>- a part of the host
>
>for /Tæya/
>- other entities
>- non living possesions
>- prepositions and directions

## Desired vs Disgusted

When an Object which is supposed to be Detached but it is used with "tæyu",
this expresses that the host cherishes or craves the object.

When an Object which is supposed to be Attached but it is used with "tæya",
this expresses that the host is disgusted with the object and wish to get rid of it.

>[!example]
> "I am too short, I wish I am taller", here we can use "tæya" to describe the speaker's height
> 
> "Kytzune Chan 's fiancce, Phox Kun", here we can use "tæyu" to describe Kytzune Chan's fiancce.
